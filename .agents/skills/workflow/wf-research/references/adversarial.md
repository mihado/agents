# Adversarial Research Branch

Independently inspect sources before evaluating any constructive position.

1. Restate the bounded decision and constraints.
2. Gather primary and contrary evidence independently; do not rely only on another worker's report.
3. Test alternative interpretations and constraint conflicts.
4. Recommend `defer` or `reject` when evidence or fit is insufficient.
5. Return the same research report format as the normal branch, with contrary evidence and residual unknowns explicit.

Do not invent an implementation solution or bypass unresolved Idea/Think work.
